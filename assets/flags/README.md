# Country flags

257 SVG assets copied unchanged from `flag-icons` 7.3.2, `flags/4x3/`, covering all 249 ISO
3166-1 countries and territories and eight additional two-letter entries.

Source: https://github.com/lipis/flag-icons/tree/v7.3.2

License: MIT, included in `LICENSE.txt`. Assets are bundled locally; no remote requests or
external CSS are used. `unknown.svg` is a local neutral fallback for unrecognized codes.
